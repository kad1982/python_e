# Добавление виджетов MyDash

Следуй контракту из `.cursor/rules/widgets.mdc`.

## Контракт

Каждый виджет в `js/widgets/` экспортирует объект по умолчанию:

```javascript
export default {
  id: 'widget-id',
  title: 'Заголовок',
  init(config) {},
  render(container) {},
};
```

## Обязательные шаги

1. Создать файл `js/widgets/{id}.js` по контракту выше
2. Импортировать и зарегистрировать в `js/registry.js`
3. Добавить id в массив `widgets` в `data/default-config.json`
4. Добавить CSS-классы в `styles/main.css` при необходимости

## Правила

- Состояние сохраняй через `js/storage.js` (`get`, `set`, `remove`)
- Не используй inline-стили (`element.style`, атрибут `style`)
- Не обращайся к DOM вне переданного `container`, кроме глобальных событий
- Один виджет — один файл; id в нижнем регистре, латиница
- Только публичные API без ключа

## Виджеты

добавить вилжеты
Список дел. Поле ввода и список задач. Задачу добавляют, отмечают галочкой, когда она выполнена, и удаляют. Список сохраняет состояние после перезагрузки страницы.
Таймер Pomodoro. Позволяет отслеживать циклы работы и отдыха по 25 и 5 минут. Есть кнопки старта, паузы и сброса. Имеется счётчик завершённых рабочих циклов. После сброса отсчёт начинается заново и не задваивается.
Цитаты. Карточка показывает случайную цитату и автора. Кнопка «Новая цитата» загружает другую цитату без обновления страницы. Данные берите через публичной API без ключа dummyjson.com/quotes/random, который отвечает прямо из браузера. Покажите сообщение, если сеть недоступна.
Курсы валют. Карточка показывает курс валюты. Данные берите через бесплатный API без ключа Frankfurter api.frankfurter.dev.

## Pomodoro

- Один `setInterval` на модуль: перед стартом и на сбросе всегда `clearInterval`
- Сброс: пауза, режим работы, 25:00, без второго таймера
- Счётчик циклов увеличивается только после полного рабочего интервала
