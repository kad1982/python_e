В рамках проекта реализовано:
- Размещение объявления. Пользователи могут разместить объявление об аренде одежды. В объявлении:
описание объекта;
стоимость аренды;
местоположение;
контактная информация для потенциальных арендаторов.
- Поиск объявлений. Пользователи могут искать объявления по нескольким фильтрам:
по ключевым словам в заголовке/тексте объявления;
по местоположению товара;
по стоимости аренды.
- Редактирование объявления. Пользователи могут редактировать свои объявления. Менять информацию в объявлении или удалять
его, если товар уже сдан в аренду и оно больше не актуально.
- Аутентификация пользователей. Функция предотвратит спам и гарантирует, что только авторизованные пользователи могут
размещать объявления или просматривать контактную информацию.
- Модерация. Объявления публикуются на сайте только после того, как проходят модерацию. Это нужно, чтобы на сайте не
появлялся спам или неуместные объявления.
- Обратная связь. Пользователь может оставить отзыв об объявлениях и продавце. Это поможет улучшить качество объявлений и
пользовательский опыт.
- Тестирование. Запуск тестов
python manage.py test --keepdb
